Founder & Full-Stack Developer

Live analytics for websites, SaaS and apps that follows one journey from the first visit to a download, install, trial and purchase. Notchlight is its first customer.

  • Built a Swift package for macOS and iOS apps that credits each install to the website visit it was downloaded from, with versions, trials and licences.
  • Built the dashboard: reports against the previous period, filters on any breakdown, CSV export, and a live view with a globe that changes the moment someone arrives or leaves.
  • Added history imports from Google Analytics, Plausible and GitHub release downloads, plans and billing through Polar, and email alerts when a site goes quiet.
  • Run it on my own server on Oracle Cloud in Docker behind Caddy, with a copy of the database sent off the server every night.
